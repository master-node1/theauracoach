# User Stories

Format: `As a <persona>, I want <capability> so that <outcome>`. IDs map to [PRD](product-requirements.md) requirements and to [acceptance criteria](acceptance-criteria.md). Priority: M = MVP, P2.

## Epic 1 — Account and onboarding

| ID | Story | PRD | Pri |
|---|---|---|---|
| US-101 | As a new user, I want to sign up with Google, Apple or email so that I can start in under a minute. | A1 | M |
| US-102 | As a user who forgot my password, I want a reset link so that I regain access without support. | A2 | M |
| US-103 | As a new user, I want onboarding split into short steps with progress so that it does not feel like a form. | A3–A5 | M |
| US-104 | As a user with a knee injury, I want to declare it so that my plan avoids aggravating movements. | A6 | M |
| US-105 | As a user who answered "yes" to a heart-related screening question, I want clear advice to see a doctor and a gentle starter plan so that I stay safe without being locked out. | A6 | M |
| US-106 | As a new user, I want a starting assessment that explains my numbers so that I trust the plan. | A7 | M |
| US-107 | As a user whose goal changed, I want to edit it and see a proposed new plan so that I stay on track. | A8 | M |
| US-108 | As a privacy-conscious user, I want to export or delete my data so that I stay in control. | I2, I3 | M |
